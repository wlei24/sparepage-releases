这些数字怎么理解
  • 数据来自 GitHub Releases 的安装包下载计数；自己测试、重复下载也可能计入，转发文件后的安装无法统计。
  • 不包含校验文件与 Source code 压缩包。已记录但后来移除的安装包保留最后一次计数，避免历史累计突然归零。
  • 新增数是两次采样之间的变化，按本次采样日期归档；任务延迟或漏跑时，不把多天增量假装分配到每一天。
  • 页面和下载汇总数据公开可读。应用剪贴板内容、设备标识和用户个人信息均不参与此看板。
  • 定时任务可能延迟，长期无仓库活动也可能被 GitHub 暂停；可从“任务状态”查看和手动运行。
